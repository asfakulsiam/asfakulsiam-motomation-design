# Common Mistakes This Skill Must Prevent

| Mistake | Why it’s wrong | Do this instead |
|---------|----------------|-----------------|
| Animating every element on scroll | Creates noise and fatigue | Animate only what serves hierarchy or story |
| WebGL / heavy shaders on utility pages | Wrong context, performance cost | Keep utility interfaces calm and fast |
| Scroll-jacking without escape | Frustrates users | Always allow normal scroll; pin sparingly |
| Auto-playing video with sound | Extremely disruptive | Never autoplay with sound |
| Parallax on body text | Hurts readability | Parallax only decorative or image layers |
| Spring / bouncy easing on serious content | Wrong emotional tone | Match easing to the mood |
| Same fade-up on every section | Feels templated | Vary direction, scale, and timing |
| Custom cursor as the only signature move | Weak and overused | Create a real compositional or interaction moment |
| Ignoring prefers-reduced-motion | Excludes users | Always ship a complete fallback |
| Long pinned sections on mobile | Feels broken | Shorten or convert to poster mode |
| Inventing metrics, testimonials, or projects | Dishonest | Only use real content |

When in doubt, apply the Restraint Gate.
