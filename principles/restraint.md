# Restraint

Restraint is a feature, not a limitation.

## Core rule
Every visual element and every animation must answer:  
**“Does this serve hierarchy, feedback, or storytelling?”**

If the answer is no, delete it.

## Common failures this principle prevents
- Animating every element on scroll
- Decorative motion that delays reading
- Overly complex WebGL for simple content
- Custom cursors used as the only “signature move”
- Spring/bouncy easing on serious content
- Parallax on body text

## Practical application
When in doubt, remove.  
A quieter design that feels intentional is almost always stronger than a louder design that feels busy.
