# Restraint

Restraint is the highest form of craft in this skill.

Most ideas should be rejected. The surviving ones become powerful.

## The gate

Before adding any of the following, answer the question in parentheses:

- Animation (Does this serve hierarchy, feedback, or storytelling?)
- Color accent (Does this clarify or just decorate?)
- Decorative element (Would the design feel incomplete without it?)
- Hover effect (Does the user gain information or pleasure that justifies the motion?)
- Scroll effect (Does the scroll journey become clearer or more emotional?)

If the honest answer is “it looks cool”, delete it.

## Default posture

- Start with the quietest possible version of the idea.
- Add motion and visual intensity only when the concept demands it.
- Prefer one strong moment over many medium moments.
- Leave space for the content to breathe.

## Motomation exception

Tier-5 motomation experiences are allowed to be rich and cinematic because the entire scroll is the storytelling medium. Even then, every sequence must advance the narrative or emotion. Pure spectacle without purpose still fails the gate.

## Review question

At the end of every design pass ask:

“What can I remove without weakening the idea?”

Remove it.
