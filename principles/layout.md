# Layout & Spatial Design

Space is active. Empty areas are not leftover; they are designed.

## Core rules

- Prefer generous negative space over dense packing.
- Align to a clear underlying structure (columns, modular grid, or deliberate asymmetry).
- Create hierarchy through scale, position, and proximity before adding decoration.
- Avoid equal padding and equal gaps everywhere. Vary rhythm deliberately.
- Use large scale jumps for impact. A single oversized element can organise an entire viewport.
- Group related content tightly; separate unrelated content with clear spatial breathing room.

## Grid approaches

- Strict modular grid for product and editorial work.
- Loose asymmetric compositions for portfolios and creative studios.
- Full-bleed sections alternating with contained content for narrative sites.
- Pinned or sticky elements only when they serve storytelling or navigation.

## Responsive behaviour

- Design mobile first in spirit, then expand.
- Prefer fluid type and spacing (clamp, container queries) over hard breakpoints when possible.
- On small screens, preserve hierarchy and breathing room rather than shrinking everything proportionally.
- Never let important text or interactive elements fall into unsafe areas (notches, home indicators).

## Common failures to avoid

- Card grids with identical padding and soft shadows
- Hero sections that are always left text / right image
- Sections that all start with the same vertical rhythm
- Overuse of max-width containers that make the site feel like a document instead of an experience

## Decision test

If removing the layout structure still leaves the content readable and hierarchical, the layout is working. If the design collapses without the grid lines, the structure was cosmetic.
