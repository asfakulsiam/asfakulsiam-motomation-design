# Typography

Typography is the primary visual system of this skill.

## Hierarchy
Establish clear levels:
- Display / hero statement
- Page title
- Section heading
- Subsection heading
- Body
- Label / caption / metadata

Use size, weight, width, case, line breaks, alignment, and spacing to create hierarchy.  
Avoid making every heading enormous.

## Rules
- Choose distinctive, high-quality typefaces. Avoid Inter, system-ui, Roboto, and other common AI defaults unless there is a strong reason.
- Prefer generous line-height for body text.
- Keep line lengths readable.
- Use fluid type (`clamp()`) with sensible minimum and maximum bounds.
- Check real content strings, not only placeholders.
- Font loading must minimize layout shift.

## Personality
Typography carries most of the brand voice.  
A strong type system can make even simple layouts feel expensive.
