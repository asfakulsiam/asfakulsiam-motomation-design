# Typography

Typography is the primary visual system of every site produced under this skill. Color, imagery and motion support type; they never replace it.

## Rules

- Choose distinctive, high-quality typefaces. Prefer families with strong character and good optical sizes when available.
- Establish a clear modular scale. Common ratios: 1.2 (minor third), 1.25 (major third), 1.333 (perfect fourth), 1.5 (perfect fifth).
- Hierarchy is created first by size and weight, second by color and position.
- Body text must remain highly readable: 16–20 px base, 1.4–1.7 line-height, comfortable measure (45–75 characters).
- Display and headline type can be extreme. Large scale, tight tracking, mixed case, or experimental cuts are encouraged when they serve the concept.
- Avoid Inter, Roboto, Open Sans, and other overused defaults unless the project specifically demands neutrality.
- Prefer variable fonts when they reduce file size and allow fine control of weight and optical size.
- Limit the number of families to two (or one + system mono) unless the concept demands more.

## Pairing logic

- Serif display + clean sans body for editorial / luxury
- Geometric sans display + humanist sans body for modern product
- Monospace for technical or brutalist moments
- One strong display face used at extreme scale can carry an entire site

## Optical decisions

- Tighten tracking on large headlines.
- Slightly increase tracking on small uppercase labels.
- Use optical sizes when the font family provides them.
- Never let line length exceed readable measure on body text.

## Hierarchy checklist

Before finalising any layout ask:

1. Can the user understand the importance of every text element without color?
2. Is the largest type the most important idea?
3. Does the type scale feel intentional rather than random?
