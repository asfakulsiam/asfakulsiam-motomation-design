# Inspiration Libraries — High-Quality Motion & Component References

This skill treats external component libraries as **inspiration sources**, not copy-paste dumps.  
Always apply the Restraint Gate, originality rules, and mood system when adapting ideas.

---

## Primary Inspiration Sources

### 1. React Bits
- Repo: https://github.com/DavidHDev/react-bits
- Site: https://reactbits.dev
- Strength: Largest open-source collection of animated React components (text, backgrounds, micro-interactions, UI effects)
- Best for: Creative text reveals, living backgrounds, refined micro-interactions
- Use when: You need high-quality motion ideas that still feel intentional

### 2. Magic UI

## How Agents Should Use These Libraries

1. **Never copy blindly.**  
   Adapt the *idea*, not the exact implementation.

2. **Match the mood:**
   - Quiet → soft, elegant, atmospheric, restrained
   - Editorial → precise, structured, clean, typographic
   - Play → kinetic, expressive, reactive, more experimental

3. **Apply the Restraint Gate.**  
   Ask: Does this serve hierarchy, feedback, or storytelling? If not, delete it.

4. **Prefer the lightest effective technique.**  
   A simple CSS or GSAP solution is often better than a heavy component.

5. **Always provide reduced-motion fallbacks.**

6. **Keep essential content in semantic HTML.**  
   Do not hide important information inside canvas or complex animation.

## Final Rule

These libraries exist to raise the quality of ideas.  
They do **not** replace the thinking sequence, the Restraint Gate, or the requirement for originality.

A great result uses inspiration intelligently.  
A weak result just pastes components.
