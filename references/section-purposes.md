# Section Purpose Guide

Before designing any section, write a one-sentence purpose. Then choose composition and motion that serve that purpose.

| Section type | Purpose | Suitable visual approaches | Suitable motion |
|--------------|---------|----------------------------|-----------------|
| Hero / Introduction | Establish identity and value | Oversized type, signature image, editorial split | One decisive reveal, restrained entrance |
| Selected Work | Prove capability | Art-directed project sequence, varied ratios | Image unmasking, focused hover, transition into case study |
| About / Studio | Explain people and point of view | Portrait, annotated timeline, artifacts | Chapter reveals, timeline progress |
| Process | Explain how work happens | Steps, diagrams, before/after | Sequential build, line drawing |
| Services | Clarify offering | Typographic list, capability map | Highlight active item, expand detail accessibly |
| Metrics / Results | Establish evidence | Accurate charts, real numbers | Count only when it adds comprehension |
| Testimonials | Build trust | Editorial quotes, real attribution | Gentle sequencing |
| Contact / Invitation | Make the next step clear | Direct invitation, short form | Focus feedback, clear success/error states |
| Footer | Close the experience and aid navigation | Compact links, credits | Usually restrained |

Variation between sections should be driven by meaning, not random novelty.
