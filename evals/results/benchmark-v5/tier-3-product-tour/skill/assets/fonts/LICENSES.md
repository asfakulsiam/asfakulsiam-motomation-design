# Template fonts

All files here are Google Fonts releases under the SIL Open Font License 1.1 (https://openfontlicense.org), downloaded 2026-10-12 from fonts.googleapis.com as the `latin` subset (Hind Siliguri: `bengali` subset). Instrument Sans and JetBrains Mono are the same files as `examples/html/lib/fonts/`. The `unicode-range` of each file is recorded in `fonts.json`, which `node scripts/build-templates.mjs` (run from the repository root) reads.
