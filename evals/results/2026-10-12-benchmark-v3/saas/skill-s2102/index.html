Tracewell Install

CLI + web app for on-call backend engineers

From 4 million log lines to the one that matters.

Tracewell ranks every line by how unusual it is compared with the last 7 days, then gives you one link that explains the incident to the whole team.

Install Tracewell brew install tracewell

01 · How it works

Three commands between the page and the cause.

  1. STEP 1

    Ingest

    tracewell ingest

    Stream logs from files, Docker or Kubernetes.

  2. STEP 2

    Ask why

    tracewell why --since 15m

    Lines are ranked by how unusual they are compared with the last 7 days.

  3. STEP 3

    Share the link

    explanation link

    Send the explanation link to the team. They see the same line and the same reason.

02 · The product working
