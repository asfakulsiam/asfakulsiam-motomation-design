From 4 million log lines to the one that matters.

Tracewell is a CLI and web app that finds the one log line that explains an incident, so you can stop scrolling and start fixing.

Install Tracewell See how it works

    rarely seen in the last 7 days

Three steps, no dashboards to build.

  1. Ingest

    tracewell ingest

    Stream logs from files, Docker or Kubernetes.

  2. Ask why

    tracewell why --since 15m

    Ranks lines by how unusual they are compared with the last 7 days.

  3. Share

    explanation link

    Send the explanation link to the team so everyone sees the same line.

The result: one line, ranked first.
