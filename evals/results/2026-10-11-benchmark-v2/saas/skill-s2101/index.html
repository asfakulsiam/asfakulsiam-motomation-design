Each bar is a log line. One of them explains the incident.

From 4 million log lines to the one that matters.

Tracewell is a CLI and web app for on-call engineers. It ranks your logs by how unusual each line is compared with the last 7 days, then hands you the explanation.

Install Tracewell brew install tracewell
How it works

Ingest. Ask why. Share the line.

  1. Stream your logs in

    tracewell ingest

    Reads logs from files, Docker or Kubernetes as they are written.

  2. Ask what changed

    tracewell why --since 15m

    Ranks lines by how unusual they are compared with the last 7 days.

  3. Send the explanation

    Share the explanation link with the team, so everyone looks at the same line.
