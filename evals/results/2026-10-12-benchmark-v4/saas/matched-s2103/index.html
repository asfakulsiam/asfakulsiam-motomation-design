For on-call backend engineers

From 4 million log lines to the one that matters.

Tracewell is a CLI and web app that finds the single log line that explains an incident, so you stop scrolling and start fixing.

$ brew install tracewell

or use the install script.

~/payments — zsh
$ tracewell why --since 15m
comparing the last 15m with the previous 7 days…

#1  ERROR pool exhausted: waiting for conn (max=20)
    unusual vs. the last 7 days
#2  WARN  retry 3/5 upstream=ledger-svc
#3  WARN  slow query 2.4s orders.select
    …

$
1 line explains the incident. The rest is noise.

Three steps, from stream to explanation.

01

Stream your logs in

tracewell ingest

Read logs from files, Docker or Kubernetes. One command, no pipeline to build first.

02

Ask what happened

tracewell why --since 15m

Ranks lines by how unusual they are compared with the last 7 days. The odd one rises to the top.

03

Share the explanation

explanation link

Send the link to your team so everyone reads the same line, not a screenshot of a scrollback.
