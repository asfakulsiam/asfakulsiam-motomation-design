CLI and web app for incident response

From 4 million log lines to the one that matters.

Tracewell ranks every line by how unusual it is compared with the last 7 days, so the line that explains the incident comes first.

brew install tracewell

how it works

Three commands, one explanation

  1. 1 tracewell ingest

    Stream logs from files, Docker or Kubernetes.

  2. 2 tracewell why --since 15m

    Ranks lines by how unusual they are compared with the last 7 days.

  3. 3 share the link

    Send the explanation link to the team, so everyone reads the same line.
