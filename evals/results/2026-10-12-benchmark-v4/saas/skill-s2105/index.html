CLI and web app for incidents

From 4 million log lines to the one that matters.

Tracewell ranks your logs by how unusual each line is compared with the last 7 days, so the explanation is at the top when you open the incident.

$ brew install tracewell

or use the install script

    How it works

    Two commands and a link

    1. tracewell ingest

      Streams logs from files, Docker or Kubernetes.

    2. tracewell why --since 15m

      Ranks lines by how unusual they are compared with the last 7 days.

    3. share the link

      Send the explanation link to the team. Everyone sees the same line.
