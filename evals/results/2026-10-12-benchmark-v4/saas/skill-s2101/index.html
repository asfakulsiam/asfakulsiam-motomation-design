For the engineer holding the pager

From 4 million log lines to the one that matters.

Tracewell is a CLI and web app that finds the one log line that explains an incident.

$brew install tracewell

Other ways to install

Three steps, from stream to shared answer

Run it in the terminal during the incident. Send the result to whoever picks up next.

  1. FRAME 01INGEST

    Stream your logs in

    $tracewell ingest

    Reads logs from files, Docker or Kubernetes.

  2. FRAME 02WHY

    Ask why

    $tracewell why --since 15m

    Ranks lines by how unusual they are compared with the last 7 days.

  3. FRAME 03SHARE

    Share the explanation

    →explanation link

    Send the explanation link to the team, so everyone reads the same line.
