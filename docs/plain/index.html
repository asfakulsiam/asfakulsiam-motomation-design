Plain variants

The library is React-first. The five components the most sections and templates use also ship without React: a CSS + HTML variant and a Tailwind variant, both running the same dependency-free script.

The five (ranked by use)

  • 1. Count Up

    examples/components/micro/count-up.tsx

    A number counts from a start value to its real value once, when it first enters the screen, with tabular figures so it doesn't jitter.
    CSS + HTML · Tailwind · source

  • 2. Split Flap

    examples/components/type/split-flap.tsx

    Each character flips through the alphabet to its value like a departure board, settling left to right; changing the value flips again.
    CSS + HTML · Tailwind · source

  • 3. Copy Confirm

    examples/components/micro/copy-button.tsx

    A copy button whose icon morphs to a tick and whose label says "Copied" for two seconds, then returns.
    CSS + HTML · Tailwind · source

  • 4. Ink Fill

    examples/components/type/ink-fill.tsx

    A statement starts in the muted colour and fills with ink word by word as the reader scrolls through it.
    CSS + HTML · Tailwind · source

  • 5. Typewriter

    examples/components/text/typewriter.tsx

    A line types itself out, character by character, when it scrolls into view, with a caret that fades once the line is complete.
    CSS + HTML · Tailwind · source
