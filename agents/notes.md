# Agent-Specific Notes

## General

This skill works with any agent that can load SKILL.md or AGENTS.md. Prefer the full thinking sequence on every new design task.

## v0 / Lovable / similar UI generators

Emphasise the thinking sequence and signature move early. These tools can produce polished defaults quickly; the skill’s job is to push them away from those defaults toward original work. Use /mutate and /motomate liberally when the first output looks too template-like.

## Claude Code / Cursor / Codex / Windsurf

Load reference files on demand. Keep context focused. When building tier 4–5, explicitly request performance and reduced-motion paths.

## Google AI Studio / Antigravity / other code-focused environments

Provide complete, runnable code. Prefer clear file structure. Include comments only when they explain non-obvious design or performance decisions.

## ChatGPT / Grok / general chat agents

Paste or reference the relevant sections of this skill. Ask the agent to run the full thinking sequence before generating code or descriptions.

## Common failure modes across agents

- Skipping the thinking sequence → generic output
- Over-animating everything → fails restraint gate
- Ignoring reduced-motion → incomplete delivery
- Choosing safe typefaces and layouts → fails anti-sameness

When any of these appear, re-run the thinking sequence or issue /mutate or /critique.
