Four Pillars of IT and Data Governance

Built to satisfy rigorous IT vendor security reviews for mid-market and enterprise importers.

PILLAR 1

Encryption at Rest & in Transit

All customer shipment records, customs documents, and API credentials are encrypted at rest using AES-256 with AWS Key Management Service (KMS) envelope encryption.

  • TLS 1.3 enforced for all external browser and API communication
  • FIPS 140-2 validated cryptographic modules
  • Automated key rotation every 90 days
PILLAR 2

Logical & Tenant Isolation

Every tenant operates within logically segregated database partition boundaries. Customer shipment records, HTS codes, and commercial invoice lines are strictly inaccessible to other network participants.

  • Row-Level Security (RLS) enforced across all persistent tables
  • Tenant identification tokens required on every database query
  • Dedicated private VPC deployment options for Global Enterprise tier
PILLAR 3

Identity & Access Governance

Enforce enterprise identity policies with SAML 2.0 and OpenID Connect integrations. Grant granular permissions across logistics coordinators, finance analysts, and external warehouse partners.

  • Native SSO integration with Okta, Microsoft Azure AD, and Ping Identity
  • Mandatory Multi-Factor Authentication (MFA) for administrative roles
  • Detailed audit logging recording every user action with timestamp and IP
PILLAR 4

Vulnerability Management & Auditing

Continuous automated code scanning, dependency tracking, and annual external penetration testing performed by accredited cybersecurity testing firms.

  • Annual independent SOC 2 Type II audit conducted by AICPA-accredited firm
  • Automated CI/CD dependency vulnerability screening
  • Formal Disaster Recovery (DR) plan with 1-hour Recovery Time Objective (RTO)
