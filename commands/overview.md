# Commands

These directional commands can be issued at any time. Apply only the requested change.

## /shape
Restructure the overall composition, hierarchy, and spatial relationships.

## /bolder
Increase visual impact: larger type, stronger contrast, more decisive scale relationships.

## /quieter
Reduce noise. Increase breathing room. Soften or remove secondary elements.

## /distill
Remove everything that is not essential. Apply the restraint gate aggressively.

## /animate
Introduce or refine motion at the current tier. Improve easing, timing, and purposefulness.

## /motomate
Escalate the experience to Tier 5. Redesign key sequences so the scroll feels like a directed film.

## /mutate
Force a new original pattern using the invention layer.

## /overdrive
Push motion intensity and visual drama to the maximum that still passes the restraint gate.

## /critique
Run a strict review. **Must use the required output format** defined in `commands/critique-format.md`.

## /signature
Report the site’s single Signature Move clearly. If the agent cannot name one specific, memorable moment, the thinking sequence was not followed.

## /polish
Refine micro-details: type spacing, easing curves, hover states, focus styles, small timing adjustments.

## /version
Report the current installed version of this skill (reads the `VERSION` file).

## /check-update
Check whether a newer version of the skill is available on the official repository.

## /update-skill
Provide clear instructions to update the skill to the latest version. Works in v0, Cursor, Claude Code, and similar environments.
