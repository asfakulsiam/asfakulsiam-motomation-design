# Neumorphism (Soft UI)

Core philosophy: elements appear extruded or pressed into the same material as the background through dual soft shadows.

## Execution

- Background and element share the exact same base color
- Light shadow on one side, dark shadow on the opposite side
- Very soft, diffused shadows (large blur, low opacity)
- Minimal borders or none at all
- Works best with simple shapes and limited hierarchy

## Best for

Simple utility interfaces, calculators, smart-home controls, experimental personal projects. Rarely appropriate for content-heavy or marketing sites.

## Critical warning

Contrast is inherently low. Text WCAG contrast carefully. Prefer higher-contrast alternatives for any text-heavy or accessibility-critical interface.

## Mutation examples

- Soft UI + one hard geometric accent
- Soft UI used only for interactive controls inside a higher-contrast layout
- Soft UI + strong typography that sits outside the soft system
