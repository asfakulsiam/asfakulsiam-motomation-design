# Invention Layer (Mad Artist Rules)

Use this when the request asks for unique / original / award-level work.

1. Force a collision between three unrelated elements.
2. Create one Signature Move that appears only once.
3. Deliberately mutate a familiar archetype.
4. Reject the first “nice” idea.
5. Prefer a memorable specific solution over a safe generic one.

Originality is not random novelty. It is intentional difference that still serves the content.
