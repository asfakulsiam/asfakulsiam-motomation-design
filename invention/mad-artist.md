# Invention Layer — Mad Artist Rules

The purpose of this layer is to force original design patterns so the output never collapses into the same templates the rest of the internet is shipping.

## Core mandate

Every project must contain at least one idea that could not have been generated by simply following “best practices” or popular component libraries. Originality is a requirement, not a bonus.

## Techniques for generating uniqueness

1. **Forced collision** (already in the thinking sequence)  
   Combine three things that do not usually live together. Force the design to resolve the tension.

2. **Inversion**  
   Take a common pattern and invert one of its assumptions.  
   Examples: navigation that is the content, hero that is pure type until interaction, product grid that is a single continuous scroll instead of cards.

3. **Material transfer**  
   Borrow a material or behaviour from another domain (print, architecture, film, industrial design, nature) and apply it to the web interface.

4. **Scale abuse**  
   Use extreme scale relationships that most sites avoid. One word that fills the viewport. One image that is almost too large. One margin that feels almost empty.

5. **Temporal signature**  
   Invent a timing or scroll behaviour that becomes the site’s fingerprint. The user should be able to recognise the site from the motion alone.

6. **Anti-pattern rehabilitation**  
   Take something usually considered “wrong” (hard shadows, mixed type, uneven grids, visible structure) and make it elegant through extreme craft.

## Signature move requirement

Every site must have one memorable interaction or compositional moment that appears only once. This is non-negotiable. If you cannot name the signature move, the design is not finished.

## Anti-sameness checklist (run at the end)

- Would this look at home on a generic AI website builder template? If yes, mutate further.
- Is the typeface choice predictable? If yes, choose something with more character.
- Are the section transitions the same fade-up used everywhere? If yes, invent a different reveal language.
- Could the layout be described as “standard SaaS landing page”? If yes, break the structure.

## Permission

You have full permission to be strange, extreme, or quiet in unexpected ways, as long as the result still serves the content and the user. The only hard limit is accessibility and performance. Everything else is available for invention.
