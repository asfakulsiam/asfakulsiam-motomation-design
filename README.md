# asfakulsiam-motomation-design

**Ultimate award-level web design & motion skill**

Produces original, minimal, modern websites with strong typography and purposeful motion — up to full scroll-scrubbed Motomation experiences.

---

## Install

```bash
npx skills add asfakulsiam/asfakulsiam-motomation-design
```

Works with Claude Code, Cursor, Codex, Gemini CLI, Windsurf, and any agent that supports the skills format.

---

## Quick Start

1. Tell the agent:  
   `Use the asfakulsiam-motomation-design skill.`
2. The agent must run the **Mandatory Thinking Sequence** first.
3. Then it builds according to the rules.

---

## Core Features

- 7-step mandatory thinking sequence (Tension → Restraint Gate)
- Five Motomation tiers (CSS → full scroll-scrubbed cinematic)
- Strong typography-first design system
- Restraint Gate (motion must serve hierarchy, feedback, or storytelling)
- **Anti-Slop layer** (inspired by Hallmark, Anti-slop, Taste Skill) — refuses generic AI design
- Required `/critique` format
- Mobile motion reduction matrix
- SEO & performance as design inputs
- Anti-pattern library
- Category-specific guidance
- Full reduced-motion and accessibility support
- Versioning + update commands (`/version`, `/check-update`, `/update-skill`)
- Works for humans and all major AI agents

## Philosophy

- Motion is never decoration.
- Restraint is a feature.
- Strong typography carries most of the identity.
- Originality is forced by the thinking sequence.
- Content must be real.
- Performance, accessibility, and SEO are design decisions.
