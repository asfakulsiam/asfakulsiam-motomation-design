# Signature Moves Library

Signature moves are the details people remember. Each recipe uses the same format:

- **Idea**: what happens, in one line
- **Why it works**: the concept it can carry
- **Build**: the minimal working code
- **The detail that matters**: the edge case that makes it feel finished
- **Off-switch**: reduced motion and touch behaviour
- **Prompt**: a paste-ready instruction for any AI tool (ChatGPT, v0, Lovable, Claude…)

Files:
- `type-signatures.md`: kinetic and variable typography
- `scroll-signatures.md`: scroll-driven reveals and transitions
- `cursor-and-micro-signatures.md`: cursor, click and small "it noticed me" moments

All entries are searchable: `node scripts/search.mjs signatures "<words>"`.

**Never ship a recipe as is.** Bend it to the concept (Thinking Sequence step 5). A recipe is a starting point for a signature, not the signature itself.
