# Structure: Shapla R1 · a kitchen radio you tune by hand

> Design reference, not code. Build this in the stack Step 0 chose (`thinking/sequence.md`); do not copy a file layout from
> anywhere into a different stack. Screenshot: `og.jpg` (and `poster.webp`, the stage's first frame). Decisions: `DESIGN.md`.
> Beat-by-beat timing: `MOTION.md`. The `index.html`, `scene.mjs` and frame files in this folder are the reference film
> build the gate measures (a frame pipeline that can't leave its folder); they are evidence, not a layout to reproduce.

- **Kind:** product launch
- **Archetype · mutation · signature:** stage · single-object · aperture
- **Tier:** 5 (one pinned stage; nothing else past Tier 1)
- **Type roles:** display Fraunces · text Schibsted Grotesk · mono JetBrains Mono
- **What it is:** Shapla R1 is an FM radio in a folded aluminium shell, with a dial you turn by hand. Pre-orders ship in March 2027.

## Chapters, in order

### 1. Hook (still, about one screen)

The title, the price and the reserve action. Nothing animates.

### 2. Stage (pinned, stepped film, about four screens of scroll)

One fixed stage, one object. The film window opens through an iris (the signature), then four numbered steps like a repair manual, each a held frame with its note: front-on ("Folded from one sheet"), a three-quarter turn showing the 48 mm depth, the five parts separating along the depth axis, and the parts closing up as the needle sweeps to a station.

- **Mobile:** its own frame set; the same steps and notes.
- **Reduced motion:** the storyboard: each step as a still in normal flow with its note; no canvas.

### 3. Specifications (still)

The spec list, held still after the film.

### 4. Order (still)

The order form: one submit, and a status line that replaces its text once.
