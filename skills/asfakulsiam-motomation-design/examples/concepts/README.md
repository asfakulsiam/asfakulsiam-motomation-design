# Brief to concept: ten worked examples

One per category. Each shows the brief, a real collision draw (`node scripts/collide.mjs --n 3 --category <id> --seed <n>`, output copied unedited apart from the two closing hint lines, so anyone can rerun it and get the same three draws), the tension, the first idea and why it was rejected, what was kept or bent from the draw, the concept block as `/shape` writes it into `DESIGN.md`, and the concept stamp.

These stop at the concept. For the build, gate and stamp that follow, see the worked examples in `examples/prompts/`.

## What the ten have in common

- **The draw is a constraint, not an answer.** One example (architecture) uses a draw exactly as drawn; the others combine two draws, take the draw's own archetype fallback, or replace one field and say why.
- **A replaced field is replaced from the brief or the category list**, never from a favourite.
- **The first idea is always written down and rejected for a reason**, usually because it is on the AI-default list or contradicts the category's job.
