# Styles

Load the file for the style the brief names, or the one the concept needs. Each file covers when to use it and when not to, type, colour, layout, motion tier, signature ideas and the main pitfall.

`minimal` · `editorial` · `swiss` · `neobrutalism` · `glassmorphism` · `neumorphism` · `flat` · `kinetic-type` · `organic` · `dark-luxe`

Search them: `node scripts/search.mjs styles "<words>"`. A style is a language, not a concept. Run the Thinking Sequence first, then choose a style that serves the concept.
