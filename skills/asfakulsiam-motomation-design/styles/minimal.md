# Style: Minimal

**Essence:** fewer things, each perfect. Space and type do the work.
**Use when:** the product or work is strong enough to stand alone: architecture, luxury, design studios, quiet portfolios.
**Avoid when:** the audience needs dense information quickly (dashboards, marketplaces).

- **Type:** one display face at a large scale, one text face. Weight contrast instead of colour contrast.
- **Colour:** warm or cool neutrals plus one accent at ≤ 3% of the screen.
- **Layout:** large margins, asymmetric placement, one focal point per screen, hairline rules for structure.
- **Motion:** Tier 1–2. Line reveals, slow image fades, precise hover states. Motion is felt, not watched.
- **Signature ideas:** Line Curtain, Proximity Weight on one word, Remembered List.
- **Pitfall:** minimal ≠ empty. Every empty area must frame something. If the page feels unfinished, add precision (captions, numbers, alignment), not decoration.
