# Style: Kinetic Type

**Essence:** typography is the image and the motion. Words move, stretch, split and react.
**Use when:** portfolios, music, events, launches, type foundries, any brand with a strong voice.
**Avoid when:** long reading content (keep body text still).

- **Type:** variable fonts with expressive axes (width, weight, optical size, custom axes). See `data/fonts.csv` for faces with axes.
- **Colour:** monochrome so the motion reads, with one accent for emphasis.
- **Layout:** type at 15–40vw, edge to edge, overlapping layers of words.
- **Motion:** Tier 2–5. SplitText choreography, variable-axis animation, scroll-velocity width, scrubbed type films.
- **Signature ideas:** Proximity Weight, Width Sprint, Letter Relay, Neighbour Moves.
- **Pitfall:** readability. Each word must be readable when still, and every mid-animation frame must be readable within 300ms.
